# Birthday Telegram Bot

Этот Telegram-бот предназначен для поздравления участников группы с днём рождения.  
Он работает на Python и проверяет каждый день, кто отмечает день рождения, чтобы отправить поздравление в указанный чат.

---

## Функции

- /start — приветствие пользователя.  
- /birthdays — выводит список всех участников и их даты рождения.  
- /check — проверяет, кто празднует день рождения сегодня и отправляет сообщение.  
- Автоматическая проверка каждый день и отправка поздравлений в чат.

## Быстрый старт

#### 1. Клонируйте репозиторий:
```bash
git clone https://github.com/raicitella/BirthdayTelegramBot.git
cd BirthdayTelegramBot
```
#### 2. Установите зависимости:
```bash
pip install pyTelegramBotAPI python-dotenv
```
#### 3. Создайте файл .env и добавте токен бота, id чата и id темы (если есть):
```bash
BOT_TOKEN=ВАШ_ТОКЕН
G_C_ID=ВАШ_ID_ЧАТА
T_ID=ВАШ_ID_ТЕМЫ  #если в чате есть темы, если их нет удалите эту строку
```
#### 4. Добавьте дни рождения участников чата

Чтобы бот мог поздравлять участников с днём рождения, добавьте их даты рождения в **трёх местах**.

1. Список дат рождения

В списке `birthdays` укажите даты рождения всех участников в формате:

```python
date(год, месяц, день)
```

Пример:

```python
birthdays = [
    date(2000, 4, 5),
    date(2000, 6, 22),
    date(2000, 5, 13),
    date(2000, 1, 1),
    date(2001, 5, 13),
]
```

> **Важно:** если у нескольких участников день рождения приходится на одну и ту же дату, укажите для них **разные годы**.

Например, если у `user1` и `user2` день рождения **13 мая**, нельзя использовать одинаковую дату:

```python
date(2000, 5, 13)
date(2000, 5, 13)
```

Используйте разные годы:

```python
date(2000, 5, 13)
date(2001, 5, 13)
```

Это необходимо потому, что `birthdaysName` является словарём, а одинаковые ключи в словаре не могут существовать одновременно.

**Год в этом случае используется только для того, чтобы даты были уникальными. В таблице ****`text1`**** указывайте настоящий день и месяц рождения.**

2. Имена участников

В словаре `birthdaysName` свяжите каждую дату рождения с именем участника:

```python
birthdaysName = {
    date(2000, 4, 5): "user1",
    date(2000, 6, 22): "user2",
    date(2000, 5, 13): "user3",
    date(2000, 1, 1): "user4",
    date(2001, 5, 13): "user5",
}
```

Дата в `birthdaysName` должна совпадать с датой из списка `birthdays`.

3. Список дней рождения в сообщении

После этого добавьте участников в Markdown-таблицу `text1`. Укажите имя и дату рождения в соответствующем месяце:

```python
text1 = """
#🎂 Дни рождения

##Январь

Имя   | Дата
------|--------
user4 | 1 января

##Апрель

Имя   | Дата
------|--------
user1 | 5 апреля

##Май

Имя   | Дата
------|--------
user3 | 13 мая
user5 | 13 мая

##Июнь

Имя   | Дата
------|--------
user2 | 22 июня
"""
```

#### 5. Запустите бота:
```bash
python main.py
